# CWA Help Desk Appointment

This project is a simple HTML form for a CWA Help Desk appointment booking page.

## Files

- `Lab-3.html` - main form markup
- `script.js` - JavaScript validation and input formatting
- `logo.png` - Swinburne logo image

## How to view the page

1. Open the project folder.
2. Double-click `Lab-3.html` in a browser, or open it in VS Code and use a browser preview.

## Form validation

The script validates the main fields, including:

- Student ID: 7 to 10 digits
- Given name and family name: letters only, up to 15 characters
- Unit selection: required radio button
- Tutor selection: required dropdown
- Date format: `dd/mm/yyyy`
- Time format: `hh:mm`

## Notes

This is a simple front-end form exercise and does not send data to a server.
